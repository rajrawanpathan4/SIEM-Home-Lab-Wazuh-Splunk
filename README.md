# SIEM-Home-Lab-Wazuh-Splunk

## About Project
This is my home lab project to practice SIEM tools for SOC Analyst role.

## Tools Used
- **SIEM:** Wazuh v4.8, Splunk Free v9.2
- **OS:** Ubuntu 22.04 LTS, Windows 10
- **Platform:** VirtualBox

## What I Did
1. Deployed Wazuh SIEM Server on Ubuntu
2. Installed Wazuh Agent on Windows VM
3. Created alerts for: Failed Login, USB Connect, Malware
4. Built 2 Dashboards in Wazuh for Security Monitoring
